# UNKNOWNS.md
## AETHER — Open Questions

---

### 0. Purpose

This document lists questions we cannot yet answer.

It exists to keep the project honest.

If we already knew the answers, it would be engineering.
We don't, so it's research.

---

### U-01

**Question:**
Is curiosity alone sufficient to generate planning?

**Why we don't know:**
Planning requires counterfactual simulation.
Curiosity only creates drive.
We don't know if drive alone can bootstrap simulation.

**What would tell us:**
If temporal continuity + curiosity (without simulation)
produces measurable planning behavior,
then curiosity is sufficient.

If not, we need to add simulation explicitly.

---

### U-02

**Question:**
Does identity require a self-model?

**Why we don't know:**
Identity is a pattern in behavior over time.
It might emerge simply from history and memory.
Or it might require the agent to model itself.

**What would tell us:**
If identity emerges (P-05) without self-model (P-02),
then self-model is not required.

If identity only emerges after self-model is added,
then it is required.

---

### U-03

**Question:**
Does creativity always require intrinsic projects?

**Why we don't know:**
Creativity might emerge from exploration + memory alone.
Or it might require persistent goals.

**What would tell us:**
If creativity (P-07) appears before projects (P-06),
then projects are not required.

If creativity only appears after projects,
then projects are a prerequisite.

---

### U-04

**Question:**
Can behavioral momentum emerge without explicit memory?

**Why we don't know:**
Momentum might be an artifact of temporal state.
Or it might require memory to create inertia.

**What would tell us:**
If momentum (P-01) appears with only temporal state,
memory is not required.

If momentum requires memory to stabilize,
then memory is necessary.

---

### U-05

**Question:**
What is the minimum mechanism set for autonomy?

**Why we don't know:**
We don't know which mechanisms are essential
and which are icing on the cake.

**What would tell us:**
Ablation experiments.

If removing a mechanism does not change observable behavior,
it was not essential.

If removing a mechanism collapses behavior,
it is essential.

---

### U-06

**Question:**
Is "agency" a continuous property or a threshold?

**Why we don't know:**
We don't know if autonomy appears suddenly
or gradually increases with complexity.

**What would tell us:**
If behavioral metrics show a phase transition,
agency may be a threshold.

If metrics increase linearly with added mechanisms,
agency may be continuous.

---

### U-07

**Question:**
Can an agent built with this methodology
produce genuinely surprising outputs
to its own designer?

**Why we don't know:**
This is the ultimate test.

If Aether never surprises us,
it is not autonomous.

If it does surprise us,
we have discovered something.

**What would tell us:**
One specific moment:

> "I didn't expect Aether to do that."

That moment is the only true measure of success.
