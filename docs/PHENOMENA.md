# PHENOMENA.md
## AETHER Research Protocol

---

# 0. Philosophy

Aether is **not** a chatbot.

Aether is **not** an optimizer.

Aether is **not** a personality simulator.

Aether is an experiment.

The objective is not to program behavior.

The objective is to discover whether increasingly rich internal mechanisms
can give rise to behavior that appears autonomous.

Rule #1:

> Never implement a behavior directly if it can emerge from a lower mechanism.

---

# 1. North Star

The entire project is driven by one question.

> Can an artificial agent develop behavior that is better explained by
its own history than by its static implementation?

If yes,
the project succeeds.

If no,
Aether remains an optimizer.

---

# 2. Research Principles

Every experiment must satisfy:

- Single primary mechanism
- Observable hypothesis
- Falsifiable outcome
- Control experiment
- Quantitative metric
- Qualitative observation

# 4. Observable Phenomena

The project does NOT evaluate features.

The project evaluates phenomena.

Current target phenomena:

P-01
Behavioral Momentum

Definition

Actions become correlated with recent history,
not only current reward.

Evidence

- autocorrelation increases
- delayed switching
- inertia

---

P-02
Self Preservation

Definition

The agent predicts consequences for itself,
not only for the environment.

Evidence

- proactive resting
- avoiding future fatigue
- sacrificing curiosity

---

P-03
Counterfactual Reasoning

Definition

The agent evaluates futures
without executing them.

Evidence

- simulated branches
- planning reversals
- hesitation

---

P-04
Internal Conflict

Definition

Multiple internal drives compete.

Evidence

- unstable decision period
- oscillation
- compromise

---

P-05
Identity

Definition

Behavior becomes increasingly predictable
from interaction history.

NOT from reward.

NOT from current state.

Evidence

Different runs converge toward different stable styles.

---

P-06
Intrinsic Projects

Definition

Persistent behavioral trajectories
appear without explicit goal programming.

Evidence

Long-term commitment.

Persistence after failure.

Reward sacrifice.

Goal mutation.

---

P-07
Creativity

Definition

Novel structures appear
that cannot be explained
only by exploration noise.

Evidence

Novel combinations.

Repeated refinement.

Unexpected but coherent outputs.

---

# 5. Anti-Phenomena

These indicate architectural failure.

A-01

Pure reward optimization.

---

A-02

Random exploration mistaken for creativity.

---

A-03

Identity implemented explicitly.

Examples

self.identity

class Personality

class Desire

---

A-04

Project objects explicitly created.

Projects must emerge.

Never be instantiated.

---

A-05

History has no explanatory power.

If deleting history changes nothing,
history is fake.

---

A-06

Behavior collapses
when randomness changes.

That indicates stochasticity,
not agency.

---

# 8. Falsification

Every hypothesis must include
conditions that invalidate it.

No hypothesis may be protected
after results are known.

---

# 9. Success Criterion

Aether succeeds
when an external observer can predict
its future behavior more accurately
from its life history
than from reading its source code alone.

At that point,
history has become a causal variable.

Not merely a log.

---

# 10. Motto

Do not add behavior.

Add mechanisms.

Observe.

Reject assumptions.

Repeat.
